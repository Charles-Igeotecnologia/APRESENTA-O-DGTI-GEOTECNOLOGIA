# Geotecnologia na Educação — SEMED / DGTI

Apresentação institucional interativa do Setor de Geoprocessamento da SEMED Manaus.

## Acesso

[Ver a apresentação](https://charles-igeotecnologia.github.io/APRESENTA-O-DGTI-GEOTECNOLOGIA/)

## Conteúdo

- Cinco frentes técnicas integradas.
- Método de trabalho em quatro etapas.
- Seis cases e portfólio de 16 soluções digitais.
- Galerias, filtros e janelas de detalhes.

## Navegação

Use a rolagem, as setas para cima e para baixo ou Page Up / Page Down. Home e End levam ao início e ao fim. A tecla F ativa a tela cheia; Esc fecha os detalhes.

## Arquivos e manutenção

`index.html` é a entrada publicada no GitHub Pages e reproduz o HTML original desta entrega. `Geotecnologia_na_Educacao_SEMED_DGTI.html` preserva o arquivo recebido. Ao revisar a apresentação, mantenha as duas cópias sincronizadas.

O site é estático, com CSS, JavaScript e imagens incorporados. As fontes Google Fonts dependem de internet; há fontes alternativas locais. Não é necessário compilar nem instalar dependências.

Os campos de mapas e demonstrações ainda não preenchidos são exibidos como pendentes. Parte das descrições do portfólio está identificada no próprio conteúdo como preliminar. A publicação da apresentação não constitui validação independente dos números, documentos ou resultados técnicos citados.

## Publicação

GitHub Pages: branch `main`, diretório raiz (`/`). O arquivo `.nojekyll` permite servir os arquivos estáticos diretamente.
